SIDELINEIQ v0.50.8 HOTFIX

Fixes the mobile game-screen crash introduced by the v0.50.7 penalty-popup conversion.

Root cause:
The penalty pane was intentionally removed from the mobile main DOM, but bindPenalty()
was still called during normal game rendering and attempted to attach onchange handlers
to penalty fields that only exist after the popup opens.

Fix:
Penalty event binding now safely checks for popup fields before attaching handlers.
The popup still binds normally after it opens.

All v0.50.7 workflow changes are retained.
