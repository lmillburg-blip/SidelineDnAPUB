Recover SidelineIQ games

Open this page on the original SidelineIQ website, in the same browser and profile that held your games. It reads saved football records without changing them.

No sign-in is needed. The downloaded file contains games and minimal team labels, without roster records; keep it private.

On iPhone, save the file to Files, then upload it in SidelineDnA Support → Recovery. If you used a Home Screen app, its storage may differ from Safari.
